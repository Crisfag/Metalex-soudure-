# Metalex Soudure

Site vitrine de **Metalex Soudure** : soudure, ferronnerie et tuyauterie industrielle à Saint-Nicolas (Liège).

Site statique (HTML + CSS, sans build), prévu pour GitHub Pages :
Settings → Pages → Branch `main` / dossier `/ (root)`.

## Ajouter une réalisation
1. Déposer la photo dans `images/` (JPG, ~1600 px de large maximum).
2. Dans `index.html`, section `#realisations`, copier un bloc `<figure class="shot">` et changer `src`, `alt` et la légende.
